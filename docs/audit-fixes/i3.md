# Fix: SQLite foreign_keys pragma is off — orphaned run_results, dead CASCADE

| Field | Value |
|---|---|
| File | `server/src/db/client.js` |
| Category | Data Integrity |
| Severity | critical |
| Effort | Low |

## Problem
better-sqlite3 does not enable foreign keys by default; the code sets journal_mode=WAL but never runs PRAGMA foreign_keys=ON. The ON DELETE CASCADE on run_results never fires, and run_results can be inserted for non-existent players, orphaning leaderboard rows and bloating the DB.

## Recommended Fix
Add db.pragma('foreign_keys = ON') immediately after opening the connection, and run a one-off migration to delete orphaned run_results rows.

## Proposed Change
```diff
- export const db = new Database(DB_PATH);
- db.pragma('journal_mode = WAL');
+ export const db = new Database(DB_PATH);
+ db.pragma('journal_mode = WAL');
+ db.pragma('foreign_keys = ON');
```
